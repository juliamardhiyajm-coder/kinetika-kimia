Belajar kinetika melalui eksperimen virtual

Ubah parameter, perhatikan perubahan grafik, lalu bangun penjelasan ilmiah berdasarkan data.

1

Buat prediksi

Prediksi bentuk kurva konsentrasi terhadap waktu untuk reaksi berorde 0, 1, dan 2.

2

Eksplorasi grafik

Atur konsentrasi awal, konstanta laju, dan orde reaksi untuk menguji prediksi.

3

Analisis dan simpulkan

Isi LKM, bandingkan data dengan model matematis, lalu unduh jawaban.

Tujuan pembelajaran. Mahasiswa mampu membedakan karakteristik grafik orde 0, 1, dan 2; menjelaskan pengaruh konsentrasi awal dan konstanta laju terhadap laju reaksi; serta menghubungkan grafik dengan persamaan laju dan persamaan terintegrasi.

Model A → B (stoikiometri 1:1), r = k[A]ⁿ. Perhitungan numerik menggunakan Euler eksplisit dengan Δt = 0,01. Adaptasi dari Scott Sinex (2007), kinetics_orders.xls yang disediakan pengajar.
